# 🍳 Recipe Master – Your Personal Cooking Assistant

### Group Members:
 [Sana Moin/BCS-2023F-286]
 [Usman Kamlani /BCS-2023F-274]

Recipe Master is a full-stack web application designed to simplify the way you find, save, and manage recipes. Built with a modern tech stack, it provides a seamless experience for food enthusiasts to explore new dishes based on ingredients they already have in their kitchen.

---

## 🚀 Features

### User Authentication & Profile:
* **Secure Login:** Users can create accounts and sign in securely to save their data.
* **Persistent Favorites:** Logged-in users can "heart" recipes to save them to their personal profile for later use.

### Smart Recipe Search:
* **Ingredient-Based Discovery:** Find recipes specifically based on what you have in your fridge.
* **Late Night Mode:** A special filter for quick, low-effort meals when you're hungry at 2 AM.

### Interactive Dashboard:
* **Responsive Design:** Optimized for both mobile and desktop so you can follow recipes while cooking.
* **Live Previews:** High-quality images and step-by-step instructions for every dish.


## 🌟 Advanced Features
### Smart Kitchen Integration
* **Nutritional API Integration:** Real-time data fetching for calories, proteins, and fats for every recipe.

* **Unit Converter:** A built-in tool to switch between Metric (grams/ml) and Imperial (cups/oz) measurements instantly.

* **Dynamic Serving Adjuster:** Automatically recalculates ingredient quantities when the user changes the "Number of Servings".

### Enhanced User Experience
* **Step-by-Step Cooking Mode:** A focused interface that displays one instruction at a time to keep your screen clean while cooking.

* **Voice Commands:** Hands-free navigation (Start, Next, Previous) so you don't have to touch your phone with messy hands.

* **Meal Planner:** A weekly calendar view where users can drag and drop recipes to plan their breakfast, lunch, and dinner.

### Community & Social
* **User Reviews & Ratings:** A comment section where users can share their "cooking tips" or photos of their finished dishes.

* **Social Sharing:** One-click sharing buttons for WhatsApp and Instagram to send recipe cards to friends.

* **Print-Friendly Mode:** A specialized CSS layout that allows users to print a clean, one-page version of the recipe.
